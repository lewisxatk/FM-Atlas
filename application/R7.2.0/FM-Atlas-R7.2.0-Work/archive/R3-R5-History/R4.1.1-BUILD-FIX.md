# R4.1.1 build fix

The first R4.1 build exposed three compile errors in `ScoutDatabase.cs`.
Three advanced-attribute SQL parameter bindings had accidentally been placed in
`GetLivePlayersForClubAsync`, where their variables do not exist. They belong
only in `SearchLivePlayersAsync`, where the query uses `$attribute`, `$min`
and `$max`. R4.1.1 removes the misplaced bindings and leaves the search
bindings intact. No database schema or existing data is changed.
