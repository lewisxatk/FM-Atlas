# FM Atlas R3.5 — Aurora Frost / CoachPro Edition

## Visual direction
A Dribbble-inspired, premium football intelligence desktop app: fresh, calm, modern and data-dense without visual clutter.

## Palette
- Frost background: `#E5F2EE`
- Soft mint: `#DCEFEA`
- Surface: `#F9FDFC`
- Teal: `#168C91`
- Lavender: `#C8C5E9`
- Primary ink: `#203B43`
- Muted ink: `#6D898A`
- Soft borders: `#D6E9E4`

## Components
- Rounded cards (19px), buttons (11px), subtle outlines.
- Soft mint-to-lavender window background.
- Teal active and primary actions.
- Light surfaces and restrained shadows/borders.
- Clear small uppercase eyebrow labels.
- Preserve readable, information-rich tables for scouting data.

## Branding
`src/FmAtlas/Assets/FmAtlas.ico` is the Windows application icon. `FmAtlas.png` is the source artwork for future use as a favicon / brand mark.

## Product layout
- Fixed left navigation.
- Main workspace with search/filter, results and selected-player intelligence columns.
- Player intelligence report remains read-only and uses the same theme.
- Generic colour/initial treatments instead of invented player photos or club crests.

## Safety and data integrity
This release changes presentation and packaging only. It does not activate editing or modify the live game process. Existing field confidence labels and read-only safeguards remain in place.
