# FM Atlas 27.1 — Acceptance and Test Plan

## Goal

This build is a broad source integration pass so that the next test cycle can exercise the desktop shell, save import, analytics, role estimates, local editing and support tooling together. It is not a claim that all research backlog items or live-game writes are complete.

## Supported workflows in this build

| Area | Available now | Evidence to capture |
|---|---|---|
| Career data | Existing FMSave save-copy bridge and retained raw extra tables | Import summary, warning list, per-table row counts |
| Search | Existing Players, Staff, Clubs and global search | Search query and result count |
| Analytics | Raw numeric fields; derived season per-90 when minutes are available | Metric name, player, season, minutes, FM Data Hub comparison |
| Role fitting | 23 transparent weighted IP/OOP estimates | Role, score, coverage, comparison with in-game familiarity |
| Local editor | CA/PA, attributes, mass Set/Add/Scale, edit history, guarded undo | Before/after Atlas local values and history rows |
| Safety | Editor OFF on app start; live writes disabled | Confirm editor lock after restart and unchanged save copy |
| Diagnostics | Quick checks, copy, log and support ZIP | Safe diagnostics output or support ZIP |
| Build pipeline | Logged restore/build and self-contained publish | `build-logs/latest-build.log` or `publish-logs/latest-publish.log` |

## Required test order

1. Build and open app with an empty Atlas database.
2. Run Tester & Logs quick checks before importing a save.
3. Import a COPY of the current FM27 Game Pass career save.
4. Record the detected game/build, validation warnings and extra-table row counts.
5. Test a raw statistic against the in-game Data Hub.
6. Test a per-90 result with the same player and season, record raw numerator and minutes, and compare.
7. Test several Role Lab roles and inspect attribute coverage; do not compare against SI stars as though they are the same metric.
8. Edit one local player's attribute, test Undo, then test stale Undo rejection after making a second change.
9. Test Mass Edit using Set, Add and Scale on a small filtered test group; check Edit History.
10. Close and reopen Atlas. Confirm Editor Studio is OFF and the save copy is unchanged.
11. Export diagnostics/support ZIP and review the contents before sharing.
12. Repeat process-detection and import tests with a Steam FM27 installation when available. Do not assume same memory profile.

## Not a release gate for this iteration

- Live process writes, live undo, transfers/loans/club/staff live editing.
- Game Pass memory offset equivalence to Steam.
- Every FMSave optional table having a curated editor/view.
- Automatic face/logo/kit/flag pack management.
- Training mod injection, BepInEx companion, match engine mod integration.

These remain separate workstreams until source coverage, build fingerprint and test fixture exist.
