## Important technical boundary

The live writer's exact PE profile match proves only that a supported game module build is recognised. It does **not** prove every player-field mapping is correct. The writer still checks identity, source bytes, range and read-back, and the UI asks the user to compare the starting CA/PA values with an independent tool. Five hidden attribute mappings remain blocked because their source offsets are not independently witnessed for FM27. User-side testing on a disposable/offline career is mandatory before regular use.

The `LiveImportPayload.ModuleSha256` property name is legacy schema/API naming. In the current profile-matched importer it stores a PE build fingerprint (`SizeOfImage` + `TimeDateStamp`), not a cryptographic SHA-256. This is documented in code and must not be presented as a file hash.
