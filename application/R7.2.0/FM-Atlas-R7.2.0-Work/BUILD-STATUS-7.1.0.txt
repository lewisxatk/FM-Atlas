WINDOWS BUILD STEPS
1. Extract the complete package to a writable folder.
2. Install the .NET 8 SDK for Windows 10/11 x64.
3. Run Build-FM-Atlas-27.bat.
4. Read build-logs\latest-build.log. A successful build reports BUILD SUCCEEDED and creates:
   src\FmAtlas\bin\Release\net8.0-windows\FmAtlas.exe
5. If restore/build fails, send build-logs\latest-build.log. Do not send the original career save.

FIRST TEST
Open FM Atlas -> Tester & Logs -> Run quick checks.
Use a COPY of an FM27 career save. The Editor Studio edits the Atlas SQLite database only; it does not edit the game or career save.
For a problem, use Copy safe diagnostics or Export support ZIP. The default support ZIP excludes the career save and Atlas SQLite database. Review any exported details before sharing.
