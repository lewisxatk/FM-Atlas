## Important correction: live editing status

R7.1.0 explicitly said live memory writes were not implemented. R7.2.0 adds `LiveMemoryEditService.cs` and documents a limited writer. The correct status is:

**Implemented in source; not yet compiled or accepted on the user's Windows/FM27 installation.**

The R7.2.0 package itself says:
- .NET 8 WPF compilation: not run.
- WPF startup: not run.
- Real save import/index: static/source inspection only.
- User's Steam/Game Pass profile match: not confirmed.
- Live Apply/Undo: not tested against the user's copied career.
- Graphics scan: not validated against the user's actual graphics directory.

A PE module fingerprint identifies a known build but does not prove every field offset. The five hidden attributes remain blocked because their offsets are inherited/unverified. Do not test live writing against an online/shared career or the user's only save.
