# FM Atlas Research Register

Research findings must include source URL, access date, supported game version, evidence type and confidence. Keep facts separate from hypotheses.

## Research areas

- Football Manager database and save formats.
- FM26/FM27 version differences and schema changes.
- Graphics folder conventions and resource resolution.
- Scouting/search/editor tools and their documented capabilities.
- Public modding projects, parsers, editors and community research.
- WPF/.NET desktop architecture and performance.
- Safe process inspection and memory-adapter design.

## Evidence labels

- **Primary:** official documentation, source code, reproducible tests, format specifications.
- **Secondary:** established community documentation or well-maintained tools.
- **Experimental:** reverse-engineering observations not yet independently reproduced.
- **Unknown:** unverified claims or assumptions.

## Initial research queue

1. Recover the actual FM Atlas source and package history before making architectural assumptions.
2. Inventory the user's previously supplied modding tools, mods and repository links from the earlier conversation.
3. Verify FM27-specific support separately from FM26; do not assume formats are identical.
4. Compare existing open-source projects and document what each can legitimately teach us.
5. Maintain a compatibility matrix for game version, data source, feature and confidence.

No external repository has been adopted as a dependency by this initial checkpoint.
