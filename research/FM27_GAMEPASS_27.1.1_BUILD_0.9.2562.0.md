## 3. FM Atlas changes in this branch

The existing hard-coded 0.9.2524.0 scanner has been parameterised around an exact `GameBuildProfile`:

- The catalog stores the 0.9.2524.0 and 0.9.2562.0 static roots independently.
- The 27.1.1 reader receives only the roots from the exact fingerprint-matched profile; it does not reuse 27.1.0 static addresses.
- The entity parser retains the predecessor object-field layout described by the 0.9.2562.0 external profile.
- The save-generation probe and in-game date read use the profile's build-specific roots.
- Live database provider keys are version-specific, preventing 27.1.0 and 27.1.1 snapshots from being mixed.
- Unknown packages, non-x64 modules or incomplete profiles are rejected before process-memory reads.

### Evidence and safety state

The 27.1.1 profile remains `ExternalReferenceOnly`. It allows an explicitly confirmed **read-only structural scan**, but does not mark data as `ReadVerified`. Field provenance remains `Mapped` until the user compares FM Atlas output against their own disposable career and the scan passes independent acceptance checks.

The connector still requests only `PROCESS_VM_READ | PROCESS_QUERY_INFORMATION`. It does not request write or operation permissions, and Save Live Changes remains disabled.

## 4. Validation required on the user's installation

1. Start FM27 27.1.1, load a manually saved disposable/offline career and wait until the loading screen has finished.
2. Start FM Atlas 1068 and accept the read-only connection confirmation.
3. Confirm the detected build is Game Pass 0.9.2562.0.
4. Confirm the save-generation marker and in-game date are plausible.
5. Compare player, staff and club totals; open several known records and verify names, unique IDs, positions, CA/PA, visible attributes and club links against the game.
6. Verify My Career's manager, current club and nation independently; do not assume the player list proves the human-manager link.
7. If a pointer validation, count, identity or date check fails, stop the session and provide `%LOCALAPPDATA%\FM Atlas\Logs\live-connection.log`. Do not repeat the scan continuously and do not enable editing.
